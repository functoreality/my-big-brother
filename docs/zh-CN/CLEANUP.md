# 手动清理

[English](../CLEANUP.md)

存储 v2 只需要清理一个地方。运行下面的只读命令找到 `daily`：

```sh
python -m my_big_brother paths
```

在文件管理器中打开它，按名称排序，选择已无活动写入的旧 `YYYY-MM-DD`
目录，直接删除。无需打开任何状态文件，也不用区分分析成功或失败。
需要释放空间时，再清空回收站。

一天的原始记录、`_analysis` 下的索引、摘录、截图拼图、草稿、
临时脚本、后操作材料，以及 `_launches` 启动日志都属于日期目录。
删除整日即可清理这一单元。
原始记录的日期按系统自然日计算，与 04:00 等复盘分界无关。
Vim 跨日会话始终保存在启动日期下，因此一次复盘也可能依赖更早日期，
不只依赖窗口覆盖的相邻两天。最终会话 diff 不能精确按日期拆分编辑活动。
分析材料仍使用被复盘的日期标签。
不要删除正在采集或复盘的活动日期，
包括仍有 Vim 会话未退出的较早启动日期。

删除表示放弃自动恢复。补跑、采集器和兼容导入器都不能重建该日期。
失败日期也可以删除，剩余步骤随之停止，已发布结果及已生效修改仍保留。
只有用户明确要求并使用 `--recreate-deleted`，才允许建立新一代工作区。
普通 `--date` 不表示获准恢复。

保留 `memory`，包括第一层的长期知识、`records` 和 `_system`。
逐日完成与放弃登记是必要的持久化事实，不是缓存。
配置及个人任务也保留。个人 profile 还可能把正式结果写到其他长期位置。

删除原始证据会限制未来重跑，低分辨率拼图不能替代原始截图。
Agent 原生会话历史属于对应应用，不由本项目删除。
