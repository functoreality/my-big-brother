# 合成数据的每日复盘示例

[English](README.md) | [简体中文](README.zh-CN.md)

这些报告展示了 Codex 对 2020-01-15 的虚构工作记录所做的复盘，
不代表任何人的真实工作经历。
英文报告是原始生成结果，中文报告是这些结果的翻译，不是另一轮分析。

输入描述了 CSV 导入器修复、安装指南更新和发布检查清单草稿。
证据包括四条 Codex 对话记录、两条 OpenCode 对话记录和一条 Bash 记录。
示例中的所有时间均使用 UTC+08:00。

| 报告 | English | 简体中文 |
| --- | --- | --- |
| 工作日志 | [Read](en/worklog.md) | [阅读](zh-CN/worklog.md) |
| 时间使用 | [Read](en/time-use.md) | [阅读](zh-CN/time-use.md) |
| 每日洞察 | [Read](en/insights.md) | [阅读](zh-CN/insights.md) |

报告区分了有记录的交互和助手自述的成果。
没有记录的时间段和人的投入时间保留为未知。

两种语言共用以下机器可读示例：

- [时间使用 JSON](time-use.json)：活动时间段、重叠证据和局限。
- [耗时样本](time-estimates.json)：经过的时间跨度，未知的人的投入时间为 `null`。

JSON 示例保留原始英文字段名和文本。
在你自己的分析中，可以配置报告使用的语言。
